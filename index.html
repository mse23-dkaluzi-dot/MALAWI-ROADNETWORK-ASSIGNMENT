Malawi Road Network

Interactive Shortest Route Finder Using Dijkstra’s Algorithm

About This Project

This web application models the main road network of Malawi as an undirected weighted graph. It contains 22 major towns and district centres connected by 27 roads. Each road has a weight representing its approximate distance in kilometres.

Select a source town and destination town, then click Find Shortest Path. The shortest route will be highlighted on the graph below.

How Dijkstra’s Algorithm Works

  1. Set the distance from the source town to itself as 0.
  2. Set the distance from the source town to every other town as infinity.
  3. Select the unvisited town with the smallest known distance.
  4. Mark that town as visited.
  5. Update neighbouring towns if a shorter route is found.
  6. Repeat until the destination is reached or all towns are visited.
